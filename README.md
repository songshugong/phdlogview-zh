## 中文说明

这是 PHD2 Log Viewer 的非官方简体中文本地化构建，用于查看和分析 PHD2 导星日志。此版本内置简体中文界面，同时保留英文和法文，可在应用的 Language 菜单中切换。

macOS 版本已做 ad-hoc 签名并打包运行库依赖，但没有 Apple Developer ID 公证。如果首次启动被 Gatekeeper 阻止，请用 Control-click / 右键选择 Open/打开。

## English README

PHD2 Log Viewer

PHD2 Log Viewer is a tool for quickly visualizing your guiding
performance and spotting problems in your PHD2 Guide Log.

Open the Quick Help item on the Help menu to get brief description of
how to navigate the log with the mouse.
